# Verdelle for VS Code

Copper and verdigris, on ink and paper. Includes **Verdelle Dark** and **Verdelle Light**.

Copy this directory to `~/.vscode/extensions/librerob.verdelle-theme-0.1.0`, reload VS Code, and choose a variant from **Preferences: Color Theme**.

The extension sets workbench colors, TextMate and semantic syntax roles, and the integrated terminal palette. Comments are upright. Editor selection has a dedicated foreground; completion menus use a quieter selected surface.

Source palettes, previews, and other ports: [librerob/verdelle](https://github.com/librerob/verdelle). MIT license. This extension is not published on the Marketplace.
